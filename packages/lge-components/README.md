# @lge/components

<!-- G  it  Hub@ S  tars   a i   l sClov  e   r -->

Zero-CSS Liquid Glass Web Components built on `@lge/core`.

```html
<script type="module">
  import '@lge/components';
</script>

<lge-button variant="prominent">Done</lge-button>
<lge-input placeholder="Search"></lge-input>
<lge-toolbar>
  <button>Back</button>
  <button>Share</button>
</lge-toolbar>
<lge-tabbar>
  <button aria-selected="true">Home</button>
  <button>Library</button>
</lge-tabbar>
```

The components are light-DOM custom elements so their native content remains
accessible, interactive and capturable by the LGE mirror pipeline.
